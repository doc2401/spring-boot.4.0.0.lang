    安装 Spring Boot

    Spring Boot 可与“经典”Java 开发工具配合使用，或作为命令行工具安装。无论哪种方式，您都需要 Java SDK v17 或更高版本。开始之前，请使用以下命令检查当前的 Java 安装：

    $ java -version

    如果您是 Java 开发的新手，或者想要尝试 Spring Boot，您可以先试试 Spring Boot CLI（命令行界面）。否则，请继续阅读“经典”安装说明。

    Java 开发人员安装指南

    您可以像使用任何标准 Java 库一样使用 Spring Boot。为此，请将相应的 spring-boot-*.jar 文件包含在您的类路径中。Spring Boot 不需要任何特殊的工具集成，因此您可以使用任何 IDE 或文本编辑器。此外，Spring Boot 应用程序也没有什么特别之处，因此您可以像运行和调试任何其他 Java 程序一样运行和调试 Spring Boot 应用程序。

    虽然您可以复制 Spring Boot jar 包，但我们通常建议使用支持依赖管理的构建工具（如 Maven 或 Gradle）。

    Maven 安装

    Spring Boot 兼容 Apache Maven 3.6.3 或更高版本。如果您尚未安装 Maven，可以按照maven.apache.org上的说明进行操作。

    在许多操作系统上，可以通过包管理器安装 Maven。 如果您使用 OSX Homebrew，请尝试运行 brew install maven。 Ubuntu 用户可运行 sudo apt-get install maven。 拥有 Chocolatey 的 Windows 用户可以从提升权限（管理员）提示符中运行 choco install maven。

    Spring Boot 依赖项使用 org.springframework.boot` 组 ID。通常，您的 Maven POM 文件继承自 `spring-boot-starter-parent 项目，并声明对一个或多个 启动器 的依赖项。Spring Boot 还提供了一个可选的 Maven 插件 用于创建可执行的 jar 包。

    有关使用 Spring Boot 和 Maven 的更多详细信息，请参阅 Maven 插件参考指南中的入门部分。

    Gradle 安装

    Spring Boot 兼容 Gradle 8.x（8.14 或更高版本）或 9.x。如果您尚未安装 Gradle，可以遵循gradle.org上的说明进行操作。

    可以使用 `org.springframework.boot`group 声明 Spring Boot 依赖。通常，您的项目会声明一个或多个starter的依赖。Spring Boot 提供了一个有用的Gradle 插件，可用于简化依赖声明并创建可执行的 jar 包。

    Gradle Wrapper

    Gradle Wrapper 提供了一种很好的方式来“获取” Gradle，以便构建项目。它是一个小型脚本和库，您将其与代码一起提交，以启动构建过程。有关详细信息，请参阅 docs.gradle.org/current/userguide/gradle_wrapper.html。

    有关使用 Spring Boot 和 Gradle 入门的更多详细信息，请参阅 Gradle 插件参考指南中的入门部分。

    安装 Spring Boot CLI

    Spring Boot CLI（命令行界面）是一个命令行工具，您可以使用它快速进行 Spring 原型开发。

    您无需使用命令行界面 (CLI) 即可与 Spring Boot 协作，但它是无需集成开发环境 (IDE) 即可快速启动 Spring 应用程序的一种便捷方式。

    手动安装

    您可以从以下任一位置下载 Spring CLI 发行版：

    • spring-boot-cli-4.0.0-bin.zip

    • spring-boot-cli-4.0.0-bin.tar.gz

    下载后，请遵循解压存档中的INSTALL.txt说明。 简而言之，在.zip文件的bin/目录中有一个spring脚本（Windows 下为spring.bat）。 或者，您也可以使用java -jar配合.jar文件（该脚本可确保类路径设置正确）。

    使用 SDKMAN! 安装

    SDKMAN!（软件开发工具包管理器）可用于管理各种二进制 SDK 的多个版本，包括 Groovy 和 Spring Boot CLI。 从 sdkman.io 获取 SDKMAN!，并使用以下命令安装 Spring Boot：

    $ sdk install springboot
$ spring --version
Spring CLI v4.0.0

    如果您为 CLI 开发功能并希望访问您构建的版本，请使用以下命令：

    $ sdk install springboot dev /path/to/spring-boot/spring-boot-cli/target/spring-boot-cli-4.0.0-bin/spring-4.0.0/
$ sdk default springboot dev
$ spring --version
Spring CLI v4.0.0

    前面的指令安装了一个名为dev的本地spring实例。它指向您的目标构建位置，因此每次重新构建 Spring Boot 时，spring都是最新的。

    您可以通过运行以下命令查看：

    $ sdk ls springboot

================================================================================
Available Springboot Versions
================================================================================
> + dev
* 4.0.0

================================================================================
+ - local version
* - installed
> - currently in use
================================================================================

    OSX Homebrew 安装

    如果您在 Mac 上使用 Homebrew，可以通过以下命令安装 Spring Boot CLI：

    $ brew tap spring-io/tap
$ brew install spring-boot

    Homebrew 将 spring 安装到 /usr/local/bin。

    如果您看不到该公式，您的 brew 安装可能已过时。 在这种情况下，请运行 brew update 并重试。

    MacPorts 安装

    如果您在 Mac 上使用 MacPorts，可以通过以下命令安装 Spring Boot CLI：

    $ sudo port install spring-boot-cli

    命令行补全

    Spring Boot CLI 包含为 BASH 和 zsh shell 提供命令补全的脚本。 您可以 source 名为 spring 的脚本（对于 zsh 为 _spring），或者将其放入您个人或系统范围的 bash 补全初始化中。 在 Debian 系统上，系统范围的脚本位于 <installation location>/shell-completion/<bash|zsh>，该目录中的所有脚本在新 shell 启动时都会执行。 例如，如果您使用 SDKMAN! 安装了它，可以手动运行该脚本，请使用以下命令：

    $ . ~/.sdkman/candidates/springboot/current/shell-completion/bash/spring
$ spring <HIT TAB HERE>
  encodepassword  help  init  shell  version
    如果您使用 Homebrew 或 MacPorts 安装 Spring Boot CLI，命令行补全脚本将自动注册到您的 shell 中。

    Windows Scoop 安装

    如果您在 Windows 上使用 Scoop，可以通过以下命令安装 Spring Boot CLI：

    $ scoop bucket add extras
$ scoop install springboot

    Scoop 将 `spring` 安装到 `~/scoop/apps/springboot/current/bin`。

    如果您看不到应用清单，您的 Scoop 安装可能已过时。 在这种情况下，请运行 scoop update 并重试。
