    提供手动提示

    为改善用户体验并进一步协助用户配置给定属性，您可以提供以下附加元数据：

    • 描述属性的潜在值列表。

    • 关联一个提供者，以便为属性附加明确的语义，从而使工具能够根据项目上下文发现潜在值列表。

    值提示

    每个提示的 name` 属性对应一个属性的 `name`。在之前显示的初始示例中，我们为 `spring.jpa.hibernate.ddl-auto 属性提供了五个值：none、validate、update、create和create-drop。每个值可能还包含描述信息。

    如果您的属性类型为Map，您可以为键和值提供提示（但不能为 Map 本身提供提示）。特殊后缀.keys和.values必须分别指代键和值。

    假设一个my.contexts将魔术String值映射到整数，如下例所示：

    • Java

    • Kotlin

    import java.util.Map;

import org.springframework.boot.context.properties.ConfigurationProperties;

@ConfigurationProperties("my")
public class MyProperties {

	private Map<String, Integer> contexts;

	// getters/setters ...

	public Map<String, Integer> getContexts() {
		return this.contexts;
	}

	public void setContexts(Map<String, Integer> contexts) {
		this.contexts = contexts;
	}

}
    import org.springframework.boot.context.properties.ConfigurationProperties

@ConfigurationProperties("my")
class MyProperties(val contexts: Map<String, Int>)

    魔法值（在本例中）为sample1和sample2。 若要为键提供额外的内容辅助，您可以向模块的手动元数据添加以下 JSON：

    {"hints": [
	{
		"name": "my.contexts.keys",
		"values": [
			{
				"value": "sample1"
			},
			{
				"value": "sample2"
			}
		]
	}
]}
    提示也可以为外部类型添加，并在使用该类型时应用。
    我们建议使用 Enum 来替代这两个值。如果您的 IDE 支持此功能，这无疑是自动补全最有效的方法。

    值提供者

    提供程序是一种为属性附加语义的强大方式。在本节中，我们定义您可以用于自身提示的官方提供程序。然而，您最喜爱的集成开发环境（IDE）可能会实现其中一些、部分或全部，也可能一个都不实现。此外，它最终也可能提供自己的提供程序。

    由于这是一个新功能，IDE 供应商必须跟上其工作原理。 采用时间自然会有所不同。

    下表总结了支持的提供者列表：

    Name Description

    any

    允许提供额外的值。

    class-reference

    自动完成项目中可用的类。通常受由 `target` 参数指定的基类约束。

    handle-as

    将属性视为由必需参数 target 指定的类型所定义。

    logger-name

    自动补全有效的记录器名称和记录器组。通常，当前项目中可用的包名和类名以及定义的组也可以进行自动补全。

    spring-bean-reference

    自动完成当前项目中可用的 Bean 名称。通常受由 `target` 参数指定的基类约束。

    spring-profile-name

    自动完成项目中可用的 Spring 配置文件名称。
    对于给定的属性，只能有一个提供者处于活动状态，但如果您可以以某种方式管理该属性，则可以指定多个提供者。请确保将功能最强大的提供者放在最前面，因为 IDE 必须使用 JSON 部分中它能处理到的第一个提供者。如果某个属性没有支持的提供者，也不会提供任何特殊的内容辅助功能。

    Any

    特殊的 `any` 提供者值允许提供任何其他附加值。如果支持此功能，则应基于属性类型应用常规值验证。

    此提供者通常用于您拥有一组值且任何额外值仍应被视为有效的情况。

    以下示例为 system.state 提供 `on` 和 `off` 作为自动完成值：

    {"hints": [
	{
		"name": "system.state",
		"values": [
			{
				"value": "on"
			},
			{
				"value": "off"
			}
		],
		"providers": [
			{
				"name": "any"
			}
		]
	}
]}

    注意，在上面的示例中，任何其他值也是允许的。

    类引用

    class-reference 提供器会自动补全项目中可用的类。此提供器支持以下参数：

    参数 类型 默认值 描述

    target

    String (Class)

    none

    应赋值给选定值的类的完全限定名称。通常用于过滤掉非候选类。请注意，此信息可以通过类型本身暴露一个具有适当上界的类来提供。

    concrete

    boolean

    true

    指定是否仅将具体类视为有效候选项。

    The following metadata snippet corresponds to the standard server.servlet.jsp.class-name property that defines the class name to use must be an HttpServlet:

    {"hints": [
	{
		"name": "server.servlet.jsp.class-name",
		"providers": [
			{
				"name": "class-reference",
				"parameters": {
					"target": "jakarta.servlet.http.HttpServlet"
				}
			}
		]
	}
]}

    处理为

    handle-as 提供者允许将属性的类型替换为更高级别的类型。这通常发生在属性具有 String 类型的情况下，因为您不希望配置类依赖于可能不在类路径中的类。该提供者支持以下参数：

    参数 类型 默认值 描述

    target

    String (Class)

    none

    要用于该属性的类型的完全限定名称。此参数为必需。

    可以使用以下类型：

    • 任何 `Enum`：列出该属性的可能值。（我们建议使用 `Enum` 类型定义该属性，因为这样无需 IDE 进一步提示即可自动完成这些值的输入）

    • Charset：支持 charset/encoding 值的自动补全（例如 UTF-8）

    • Locale：本地化名称的自动补全（例如 en_US）

    • MimeType：支持内容类型值（如 text/plain）的自动补全。

    • Resource：支持自动完成 Spring 的 Resource 抽象，以引用文件系统中的文件或类路径上的文件（例如 classpath:/sample.properties）。

    如果可以提供多个值，请使用 Collection 或 Array 类型来告知 IDE。

    以下元数据片段对应于定义要使用的变更日志路径的标准 spring.liquibase.change-log 属性。它实际上在内部作为一个 Resource 使用，但不能作为此类暴露，因为我们需要保留原始的 String 值以传递给 Liquibase API。

    {"hints": [
	{
		"name": "spring.liquibase.change-log",
		"providers": [
			{
				"name": "handle-as",
				"parameters": {
					"target": "org.springframework.core.io.Resource"
				}
			}
		]
	}
]}

    日志记录器名称

    logger-name 提供者会自动补全有效的记录器名称和记录器组。通常，当前项目中可用的包名和类名可以自动补全。如果启用了组（默认）且在配置中识别出自定义记录器组，则应为其提供自动补全功能。特定框架可能还具有额外的魔法记录器名称，也可以予以支持。

    此提供者支持以下参数：

    参数 类型 默认值 描述

    group

    boolean

    true

    指定是否应考虑已知组。

    由于记录器名称可以是任意名称，此提供者应允许任何值，但可以突出显示项目中类路径中不可用的有效包和类名。

    以下元数据片段对应于标准 logging.level 属性。键为记录器名称，值对应于标准日志级别或任何自定义级别。由于 Spring Boot 内置定义了一些记录器组，因此已为这些组添加了专用的值提示。

    {"hints": [
	{
		"name": "logging.level.keys",
		"values": [
			{
				"value": "root",
				"description": "Root logger used to assign the default logging level."
			},
			{
				"value": "sql",
				"description": "SQL logging group including Hibernate SQL logger."
			},
			{
				"value": "web",
				"description": "Web logging group including codecs."
			}
		],
		"providers": [
			{
				"name": "logger-name"
			}
		]
	},
	{
		"name": "logging.level.values",
		"values": [
			{
				"value": "trace"
			},
			{
				"value": "debug"
			},
			{
				"value": "info"
			},
			{
				"value": "warn"
			},
			{
				"value": "error"
			},
			{
				"value": "fatal"
			},
			{
				"value": "off"
			}

		],
		"providers": [
			{
				"name": "any"
			}
		]
	}
]}

    Spring Bean 引用

    spring-bean-reference 提供者自动完成当前项目配置中定义的 Bean。 此提供者支持以下参数：

    参数 类型 默认值 描述

    target

    String (Class)

    none

    应可赋值给候选者的 Bean 类的完全限定名。通常用于过滤掉非候选者 Bean。

    以下元数据片段对应于定义要使用的 MBeanServer bean 名称的标准 spring.jmx.server 属性：

    {"hints": [
	{
		"name": "spring.jmx.server",
		"providers": [
			{
				"name": "spring-bean-reference",
				"parameters": {
					"target": "javax.management.MBeanServer"
				}
			}
		]
	}
]}
    绑定器无法感知元数据。 如果您提供该提示，您仍然需要使用 ApplicationContext 将 Bean 名称转换为实际的 Bean 引用。

    Spring 配置文件名称

    spring-profile-name 提供程序会自动补全当前项目配置中定义的 Spring 配置文件。

    以下元数据片段对应于定义要启用的 Spring 配置文件名称的标准 spring.profiles.active 属性：

    {"hints": [
	{
		"name": "spring.profiles.active",
		"providers": [
			{
				"name": "spring-profile-name"
			}
		]
	}
]}
